Roslindale web fonts (David Jonathan Ross, djr.com), served with the site.

The font files aren't in the repository. The instructor's copy uses .woff2 files converted from
DJR's free "Testing" (trial) fonts, and DJR's testing license covers evaluation and internal
testing, not redistribution. Without them, the site falls back to Iowan Old Style, Palatino,
or Georgia.

To use Roslindale, buy a license at djr.com/roslindale and put the .woff2 files here with these
names (static/style.css loads them):

  roslindale-text-regular.woff2        roslindale-text-italic.woff2
  roslindale-text-medium.woff2         roslindale-text-semibold.woff2
  roslindale-text-bold.woff2           roslindale-text-bold-italic.woff2
  roslindale-display-regular.woff2     roslindale-display-semibold.woff2
  roslindale-display-bold.woff2
